## 产品「轻记账」速览

一款轻量级的个人日常收支记录与统计分析工具，核心是「**3 秒记一笔，看懂钱花在哪**」。

- **记录**：支出/收入双类型、宫格分类选择、数字键盘（含加减连续运算）、补记历史日期
- **查看**：账单流水按日分组、月度收支汇总、分类占比环形图（支持点击下钻明细）
- **轻量**：纯前端 + localStorage 本地持久化，无账号、无广告、无服务端

### 设计规范

遵循 PRD 5.6「粉嫩可爱风」视觉规范：

- 主色樱花粉 `#FF9EBB` / 深蜜桃粉 `#F76C99`，奶油白背景 `#FFF7FA`
- 卡片圆角 20px、胶囊按钮、圆体数字、粉调柔光投影
- 图表专用色板经过色觉障碍（CVD）与对比度校验：
  `#E87BA4` 樱花粉 · `#EDA100` 暖黄 · `#1BAF7A` 薄荷绿 · `#8A6FD1` 芋紫 · `#EF7A45` 奶橘 · `#4E9BE0` 天蓝

## 开发

```bash
# 启动本地预览（纯静态站点，无需构建）
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 技术栈

- 静态站点：原生 HTML / CSS / JavaScript（ES Modules），无构建步骤
- 数据持久化：localStorage
- 图表：SVG 手绘环形图（dasharray + 圆角端点）
- 协作工具：Claude Code + GitHub MCP Server
